# docs/

Place the walkthrough video here as **`demo.mp4`** — the project README links to
`docs/demo.mp4`.

- Add the file: copy your recording to `docs/demo.mp4`, then commit it:
  ```bash
  git add docs/demo.mp4 && git commit -m "Add demo walkthrough video" && git push
  ```
- Tip: for an inline video player on the GitHub README, open the README on
  github.com, drag the video into the editor, and GitHub generates an embeddable
  `user-attachments` URL you can paste in — a committed `.mp4` renders as a
  download link instead.
